# Redação 1000 Toolkit

Crie uma LANDING PAGE DE VENDAS PROFISSIONAL, MODERNA,

CONVINCENTE E OTIMIZADA PARA CONVERSÃO para um produto

digital educacional chamado:

KIT REDAÇÃO NOTA 1000

PREÇO:

R$ 19,90 — pagamento único.

O produto é destinado principalmente a estudantes que irão

fazer ENEM, vestibulares ou outras provas que exigem redação.

A página NÃO deve ser excessivamente longa.

Quero uma página direta, visual, profissional e extremamente

bem trabalhada no MOBILE.

A pessoa deve entender rapidamente:

1. Qual problema o material resolve

2. O que ela vai receber

3. Como o material pode ajudá-la a estudar

4. Como é o material por dentro

5. Por que vale R$19,90

6. Como comprar

==================================================

CONCEITO PRINCIPAL DA OFERTA

==================================================

A principal dor que queremos trabalhar é:

O aluno conhece o assunto, mas chega diante da folha e

não sabe como começar, desenvolver os argumentos ou concluir.

Outra grande dor:

“E se cair um tema que eu não sei desenvolver?”

O produto deve ser apresentado como uma CAIXA DE FERRAMENTAS

PARA ESTUDAR REDAÇÃO.

Não vender apenas uma coleção de PDFs.

A percepção deve ser:

“Eu vou ter exemplos, estruturas, ideias e materiais de apoio

para saber melhor como construir uma redação.”

O produto contém:

+150 Redações Prontas para Estudar

+100 Estruturas Prontas de Redação

+50 Ideias e Argumentos para Diferentes Temas

+30 Frases para Ligar e Organizar suas Ideias

+ Mapas Mentais de Redação
